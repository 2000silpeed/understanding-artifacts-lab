삽입 정렬: key와 하나의 빈칸

이미 정렬된 왼쪽 구간에 새 값을 넣습니다. key를 따로 보관하고, 더 큰 값을 오른쪽으로 옮긴 다음 빈칸을 채워 봅시다.

입력이나 예제를 바꾸면 추적이 처음부터 다시 계산됩니다. # 표시는 원래 인덱스입니다.

예제와 카운터

[8,3,5,2]는 [2,3,5,8]이 됩니다. 값 비교 6회, 이동 5회, 삽입 3회, 배열 쓰기 8회입니다. [6,1,4,2,5]는 비교 8회, 이동 5회입니다. 비교는 값끼리의 > 검사만 세며, 인덱스 경계 검사는 제외합니다. key를 읽는 것은 배열 쓰기가 아닙니다. 이 수치는 실행 시간 측정이 아닙니다.

연산과 비용

i는 이번에 넣을 값의 원래 위치, j는 비교하는 왼쪽 위치입니다. 테두리가 강조된 왼쪽 구간은 이번 삽입의 정렬 구간이며, key 보관 중에는 빈칸을 포함할 수 있습니다. 엄격한 > 비교라서 같은 값은 서로를 넘어가지 않습니다. # 태그로 안정성을 확인하세요.

이미 정렬되면 최선 O(n), 역순이면 최악 O(n²)입니다. 알고리즘은 key 하나의 추가 공간으로 제자리 정렬합니다. 이 교육 화면은 되돌아보기를 위해 스냅샷을 저장하므로 화면 구현 자체의 메모리는 O(1)이 아닙니다.
