# 첫 번째 그래디언트 업데이트

## 준비와 목표
앞선 로짓·소프트맥스·원핫·타깃 확률·음의 로그 손실 수업을 연결해요. 이 수업에서는 국소 기울기, 유한 차분, 학습률을 새로 정의해요. 목표는 `p−y`의 부호로 로짓의 변화 방향을 예측하고, 한 번 업데이트한 뒤 손실을 다시 계산하는 거예요.

## 정의 → 예 → 계산
로짓 `z`는 확률로 바꾸기 전 점수예요. 확률 벡터 `p`는 안정적인 소프트맥스로 구해요. 정답 벡터 `y`는 타깃 칸만 1인 원핫이에요. 손실은 `L=−ln(p_target)`이에요. `ln`은 자연로그이고 정답 확률 1에서 손실 0, 확률이 작아질수록 손실이 커져요.

`z=[1,0,−0.5]`, 타깃 ID 1이면 `p≈[0.628532,0.231224,0.140244]`, 초기 손실은 약 `1.464369`예요. 그래디언트는 로짓 각 칸을 조금 바꿀 때의 손실 기울기예요. 이동 폭 `ε=0.00001`에서 `(L(z+εe_i)−L(z−εe_i))/(2ε)`를 실제로 계산해 미분 결과 `g=p−y`와 비교해요. 미분식 유도는 이번 수업의 범위 밖이에요. `e_i`는 한 칸만 1인 이동 방향 벡터예요.

정답 칸에서는 `p_1−1≈−0.768776`이고, 나머지는 양수예요. 양수 학습률 `η=0.4`로 `z_new=z−ηg`를 적용하면 음수 기울기를 빼므로 정답 로짓이 올라가요. 실제 실행에서 새 로짓은 `[0.748587,0.307510,−0.556098]`, 새 확률은 `[0.522302,0.336019,0.141679]`, 새 손실은 약 `1.090586`이에요. 실습의 0 학습률은 세 칸이 그대로인 경계 사례예요. 출력의 `−0.000000000000000`은 배정밀도 덧셈의 작은 음수 반올림이지 정확한 합이 음수라는 수학적 주장이 아니에요.

## 구현과 한계
Python과 C++17은 같은 기본 입력을 실제 실행하고 결과를 비교해요. 실습도 같은 계산을 사용해요. 최대 로짓을 빼서 지수 오버플로를 피하고, 손실은 `(max(z)−z_target)+ln(sum(exp(z−max(z))))`로 계산해 확률 언더플로에 덜 민감하게 만들었어요. 빈 배열·비유한 로짓·잘못된 타깃을 거부해요. 실습 학습률은 0 이상의 유한한 숫자여야 하고, 새 로짓 또는 손실이 유한 범위를 벗어나도 오류를 표시해요. Python/C++의 저수준 update 함수는 내부에서 검증된 길이와 유한 학습률을 전달한다는 전제를 두고, 실습 경계 검사와 구분해요.

학습률 20의 단일 로짓 업데이트는 정답 확률을 약 `0.9999999923`으로 높여요. 이 예에서 발산이 관측됐다는 주장은 하지 않아요. 그렇다고 모든 신경망이나 반복 학습에서 큰 학습률이 좋은 것도 아니에요. 직접 로짓을 최적화하는 계산 예이고, 임베딩/가중치 역전파나 트랜스포머 학습은 아직 아니에요. 숫자는 화면에서 여섯 자리로 반올림하고 내부 계산은 배정밀도예요. 유한 차분은 구현 검산이지 임의 프로그램의 정확성 증명은 아니에요.

## 전이 질문
학습률을 0으로 바꾸면 새 로짓은 어떻게 되나요? 먼저 예측하고 실습에서 확인해요. `0×g=0`이므로 모두 그대로예요. 정답 칸 음수 기울기와 양수 학습률에서는 왜 값이 올라가는지도 직접 설명해 보세요.
