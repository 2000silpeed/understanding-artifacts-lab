키는 번호, 값은 과일 이름이에요. 비음수 정수 키만 허용하고 네 버킷을 써요. 나머지는 나눈 뒤 남는 수예요. key % 4로 칸을 고른 다음 체인의 키를 정확히 비교해요. 다른 키의 같은 버킷은 충돌이고, 같은 키의 새 값은 갱신이에요.

이 페이지는 실제 Python 실행 기록 전체를 포함해요. 외부 글꼴은 요청하지 않으며 설치된 한국어 대체 글꼴을 사용해요. 표준 dict의 내부 구현을 재현하는 페이지는 아니에요.
