# 수업 커리큘럼

## 주제
위상 정렬, 먼저 해야 할 일을 차례로 꺼내기

## 선행 지식
- 방향 그래프를 정점과 화살표로 읽는다.
- 큐에 먼저 들어온 항목을 먼저 꺼내는 흐름을 안다.

## 첫 정의
의존성 `u → v`는 `u`를 `v`보다 먼저 처리해야 한다는 뜻이다. 진입차수는 아직 남은 선행 간선의 수다. 진입차수가 영인 정점만 현재 처리할 수 있다.

## 관찰 가능한 학습 목표
학습자는 고정된 방향 그래프를 보고, 큐에서 정점을 꺼내며 진입차수를 줄이는 Kahn 알고리즘의 위상 순서를 trace와 대조할 수 있다. 처리한 정점 수가 전체 정점 수보다 작게 끝나면 순환으로 판정한다.

## 핵심 입력
정점 `A`, `B`, `C`, `D`, `E`, `F`와 간선 `A→C`, `B→C`, `B→D`, `C→E`, `D→E`, `F`를 사용한다. 초기 큐는 `A`, `B`, `F`다.

## 예측 질문
`C`를 처리하기 전에는 `A`만 처리했다. `C`의 진입차수가 바로 영이 될까? 답은 아니다. `B`에서 오는 간선이 남아 있기 때문이다. 또 목표를 처음 발견했을 때 멈추는 것이 아니라, 큐가 빌 때까지 처리하며 순환을 판정한다.

## 전이 입력과 경계
`E→B`를 추가하면 `B`, `C`, `D`, `E`가 남고 출력은 `A`, `F`에서 멈춘다. 이 입력의 실제 순환은 `B→C→E→B`와 `B→D→E→B`이며 `D`도 순환의 구성원이다. 다만 일반적으로 잔여 정점 모두가 순환 구성원이라는 뜻은 아니므로 도달성을 따로 확인한다. 빈 그래프, 한 정점, 고립 정점, self-loop, 잘못된 끝점, 중복 간선을 실행한다. 중복 간선은 실행 전 거절하고, self-loop는 유효한 입력이지만 순환을 만든다.

## 실행 계약
Python과 C++17 구현은 같은 기본 출력, trace, edge 출력, transfer 출력을 낸다. 각 trace event는 한 동작 직후의 큐, 진입차수, 출력, 처리 목록 snapshot을 가진다. snapshot 복사 비용은 알고리즘의 `O(V+E)` 비용과 별도다.
