플로이드–워셜 실습

경유지 k를 A부터 하나씩 허락하며, 표의 모든 칸에 같은 질문을 던집니다: i에서 k를 거쳐 j로 가면 더 짧은가?

지도

거리 표 (행 = 출발 i, 열 = 도착 j, ∞ = 아직 모름)

바뀐 칸 기록

    코드 (examples/floyd_warshall.py 와 같은 규칙)

    for k in range(n):          # 경유지
    for i in range(n):      # 출발
        for j in range(n):  # 도착
            d = via(dist, i, k, j)   # i→k + k→j (하나라도 ∞면 ∞)
            if shorter(d, dist[i][j]):
                dist[i][j] = d
                nxt[i][j] = nxt[i][k]  # 첫걸음 기록

    그래프 직접 바꾸기

    형식: 첫 줄 정점수 간선수, 다음 줄마다 출발 도착 거리. 거리는 정수(음수 가능). # 뒤는 주석입니다.

    음수 간선은 괜찮지만, 돌수록 짧아지는 음수 사이클이 있으면 최단 거리가 정의되지 않습니다. 그때는 대각선(자기 자신까지의 거리)이 0보다 작아집니다.

    정점이 많을수록 칸 비교는 정점 수의 세제곱만큼(4개면 64번) 늘어납니다.
