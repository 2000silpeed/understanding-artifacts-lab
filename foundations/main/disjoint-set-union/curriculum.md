# 오늘의 DS: 서로소 집합과 대표 찾기

## 대상과 선행지식
- 배열 인덱스와 트리의 부모 연결을 읽을 수 있는 초보 학습자예요.
- 노드의 부모를 따라 루트에 도착하는 과정을 짧게 복습해요.

## 관찰 가능한 학습목표
수업이 끝나면 학습자는 부모 배열과 크기 배열을 보고 두 노드가 같은 집합인지 판정하고, union-by-size와 path compression이 실제 parent 상태를 어떻게 바꾸는지 설명할 수 있어요.

## 고정 실행 계약
- 노드 ID는 음이 아닌 정수이며 기본 입력은 `0`부터 `5`까지예요.
- 시작할 때 모든 노드는 자기 자신을 부모로 삼는 singleton이에요.
- `union(0,1)`, `union(2,3)`, `union(1,2)`를 실행하고 동률에서는 더 작은 root를 대표로 골라요.
- `same(0,3)`은 참, `same(0,4)`는 거짓, `union(0,3)`은 중복이라 변화가 없어요.
- `find(3)` 전 경로는 `3 → 2 → 0`, 압축 후 경로는 `3 → 0`이에요.
- 전이에서는 `union(4,5)` 뒤 `same(0,5)`가 거짓이고, `union(3,5)` 뒤 참이에요.
- `N=0`은 유효한 ID가 없고, `N=1`의 자기 union은 변화가 없다는 정책을 Python, C++, HTML에서 같게 사용해요.
- parent와 size의 전체 snapshot은 화면용 계측이며 알고리즘 자체의 비용과 분리해요.

## 수업 흐름
정의 → 여섯 singleton → union-by-size → find와 path compression → 예측과 reveal → Python·C++ 실행 → 전이 → 복잡도와 한계.

## 범위 밖
그룹 분할과 삭제는 구현하지 않아요. 개별 연산을 최악의 상수 시간이라고 말하지 않아요. 두 최적화를 함께 쓸 때 여러 연산의 amortized `O(alpha(n))` 경계를 소개하되 `alpha`의 정의를 전개하지 않아요.
