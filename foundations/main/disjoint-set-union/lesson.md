# 교안: 서로소 집합, 대표로 같은 그룹인지 확인하기

## 첫 질문
서로 겹치지 않던 그룹을 몇 번 합친 뒤, 두 번호가 같은 그룹인지 빠르게 확인하려면 무엇을 저장해야 할까요? 부모 연결과 대표 하나를 저장하면 그룹의 모양을 따라갈 수 있어요.

## 핵심 낱말
서로소 집합은 처음에는 서로 겹치지 않는 그룹이에요. 각 원소는 `parent`를 하나씩 가지고, 부모를 반복해서 따라가면 자기 자신을 부모로 가진 `root`에 도착해요. 이 root가 현재 그룹의 대표예요.

`find`는 한 원소에서 root를 찾고, `union`은 두 root를 연결해 한 그룹으로 합쳐요. `same`은 두 번의 find 결과가 같은지 비교해요.

## 작은 실행
노드 `0`부터 `5`까지는 처음에 여섯 singleton이에요. `union(0,1)` 뒤에는 `0`이 대표가 되고, `union(2,3)` 뒤에는 `2`가 대표가 돼요. 크기가 같은 두 그룹을 `union(1,2)`로 합칠 때는 더 작은 root인 `0`을 대표로 선택해요.

크기가 큰 그룹의 root 아래에 작은 그룹을 붙이는 규칙을 union-by-size라고 해요. size는 root에서만 의미가 있고, 자식 칸의 size는 읽지 않아요.

## 경로 압축
`3`의 부모 경로는 `3 → 2 → 0`이에요. find로 대표를 확인할 때 지나간 노드의 parent를 root로 직접 바꾸면 다음 경로는 `3 → 0`이 돼요. 같은 집합과 대표는 유지되지만 원래의 관계 그래프를 복원하는 기능은 아니에요.

## 코드와 경계
Python과 C++ 정본은 같은 부모와 크기 규칙을 직접 반복문으로 구현해요. 음이 아닌 정수 ID만 허용하고, 범위를 벗어나면 거절해요. 빈 구조와 한 원소 구조도 별도 edge 실행으로 확인해요.

두 최적화를 함께 쓴 여러 연산의 amortized `O(alpha(n))` 경계를 말할 수 있지만, 한 번의 연산이 항상 상수 시간이라는 뜻은 아니에요. 초기화와 저장은 `O(n)`이고, 화면용 full snapshot 복사는 계측 비용이에요.

## 전이와 정리
`union(4,5)` 뒤에는 `0`과 `5`가 아직 다른 그룹이에요. 이어서 `union(3,5)`를 실행하면 두 그룹이 연결되고 `same(0,5)`가 참이 돼요. 대표를 찾고 parent를 짧게 만드는 두 규칙이 서로소 집합의 핵심이에요.
