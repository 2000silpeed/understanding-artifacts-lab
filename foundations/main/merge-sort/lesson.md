# 병합정렬 수업 노트

## 수업 목표

이 수업을 끝내면 다음을 말하고 직접 따라 할 수 있어요.

1. 병합정렬을 **작게 나눈 뒤 정렬된 구간을 병합하는 방법**으로 설명해요.
2. 재귀의 기저 사례로 빈 구간과 원소 하나 구간을 구분해요.
3. `[8, 3, 6, 2]`의 분할 순서와 병합 순서를 추적해요.
4. 병합에서 왼쪽과 오른쪽의 맨 앞 원소만 비교하는 이유를 말해요.
5. 같은 값이면 왼쪽을 먼저 선택해 안정성을 지키는 규칙을 설명해요.
6. 실제 실행에서 최종 결과 `[2, 3, 6, 8]`과 비교 횟수 5를 확인해요.
7. 시간 `O(n log n)`, 추적 제외 임시 배열 `O(n)`, 호출 스택 `O(log n)`을 조건과 함께 말해요.

## 핵심 정의

병합정렬은 다음 순서의 비교 기반 정렬이에요.

1. 배열 구간을 두 구간으로 나눠요.
2. 각 구간을 재귀적으로 정렬해요.
3. 정렬된 두 구간의 앞 원소를 비교하고 더 작은 원소를 임시 배열에 넣어요.
4. 한쪽이 비면 다른 쪽의 남은 원소를 그대로 이어 붙여요.

빈 구간과 원소 하나 구간은 이미 정렬된 구간이므로 더 나누지 않고 반환해요. 이 수업은 작은 입력을 다루지만, 빈 입력도 종료 조건으로 명시해요.

## canonical 예시

입력은 `[8, 3, 6, 2]`예요.

```text
[8, 3, 6, 2]
├─ [8, 3]
│  ├─ [8]
│  └─ [3]
└─ [6, 2]
   ├─ [6]
   └─ [2]
```

첫 병합은 `[8]`과 `[3]`이에요. `8`과 `3`을 한 번 비교해서 `3`을 넣고, 남은 `8`을 이어 붙여 `[3, 8]`을 만들어요. 오른쪽은 같은 방식으로 `[2, 6]`이 돼요.

마지막 병합은 `[3, 8]`과 `[2, 6]`이에요.

| 비교 | 선택 | 임시 결과 |
|---|---|---|
| `3` 대 `2` | `2` | `[2]` |
| `3` 대 `6` | `3` | `[2, 3]` |
| `8` 대 `6` | `6` | `[2, 3, 6]` |
| 한쪽이 비어 있음 | 남은 `8` 연결 | `[2, 3, 6, 8]` |

왼쪽 병합 1회, 오른쪽 병합 1회, 마지막 병합 3회로 총 비교는 5회예요. `trace.json`은 이 분할과 각 선택을 실제 Python·C++17 실행에서 계산해 기록해요.

## 안정성

중복 입력은 `[2A, 1X, 2B, 1Y]`로 표시했어요. 숫자만 보면 `2, 1, 2, 1`이고, 문자는 원래 순서를 확인하기 위한 꼬리표예요. 비교 조건을 `left.value <= right.value`로 두면 같은 값일 때 왼쪽 원소가 먼저 나와요. 결과는 `[1X, 1Y, 2A, 2B]`이고, 같은 값 안에서 원래 순서가 보존돼요.

`<`만 사용하면 같을 때 오른쪽을 먼저 선택할 수 있어 안정성이 달라져요. 따라서 안정성은 정렬 결과의 값만 확인해서는 알 수 없고, 동률을 처리하는 규칙과 꼬리표를 함께 확인해야 해요.

## 코드 계약

`canonical.py`와 `canonical.cpp`는 같은 입력과 같은 추적 계약을 실행해요.

- `--trace` 없이 실행하면 `expected.txt`와 같은 설명 출력이 나와요.
- `--trace`를 주면 분할, 기저 사례, 병합 비교, 정렬 결과, 비교 횟수를 JSON으로 출력해요.
- Python과 C++17의 JSON은 키 순서를 정렬해서 의미적으로 비교하고, 사람에게 보여 주는 stdout은 바이트 단위로 비교해요.
- empty와 single 경계 케이스, duplicate 안정성 케이스도 별도로 실행해요.

## 복잡도와 메모리

추적 기록을 제외한 알고리즘 자체에만 시간 O(n log n), 임시 배열 O(n), 호출 스택 O(log n)이 적용돼요. 현재 Python/C++ 시연 구현은 --trace 없이도 매 비교의 결과 접두사 전체를 복사해 보관하므로 최악 시간과 저장 공간은 O(n²)이에요.

입력 길이를 `n`이라고 하면 한 병합 층에서 모든 원소를 한 번씩 다룰 수 있어 `O(n)`이에요. 구간을 절반씩 나누므로 층 수는 `O(log n)`이고, 전체 시간은 `O(n log n)`이에요.

이 수업의 이해하기 쉬운 구현은 병합마다 임시 배열을 만들어요. 한 병합에서 필요한 임시 공간의 최대 크기는 `O(n)`이에요. 재귀 호출이 만드는 호출 스택 깊이는 구간이 절반씩 줄기 때문에 `O(log n)`이에요. 실제 라이브러리 구현은 버퍼를 재사용하거나 반복문으로 작성해 상수와 메모리 동작을 바꿀 수 있지만, 여기서는 분할·앞 원소 비교·남은 구간 연결을 보이는 것이 목적이에요.

## 전이 연습

`[5, 1, 4, 2]`는 먼저 `[5, 1]`과 `[4, 2]`로 나눠요. 그 뒤 각각을 `[5]`, `[1]`, `[4]`, `[2]`로 나누고, 작은 병합 결과를 만든 뒤 마지막에 두 정렬 구간을 다시 병합해요. 새 배열에서 먼저 분할 트리를 그리고, 각 병합에서 현재 앞 원소와 선택된 원소를 적으면 절차를 재현할 수 있어요.
