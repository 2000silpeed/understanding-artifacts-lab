# 펜윅 트리 실습

같은 예제의 구간 합과 점 갱신을 직접 조작합니다.

실행: `python3 examples/run_examples.py` (Python 3, C++17 컴파일러 필요). 또는 `python3 examples/fenwick.py`, `g++ -std=c++17 examples/fenwick.cpp -o /tmp/fenwick && /tmp/fenwick`.

`lab.html`은 외부 파일 없이 브라우저에서 열 수 있습니다. 웹 페이지의 계산 엔진은 같은 소스에서 왔으며, 글꼴·다운로드 링크만 배포용으로 덧붙였습니다.
