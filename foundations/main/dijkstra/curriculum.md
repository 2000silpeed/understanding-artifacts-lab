# 커리큘럼: 음이 아닌 가중치의 최단 경로

## 선행지식
- 그래프의 정점과 방향 간선을 읽고, 간선의 가중치를 더할 수 있어요.
- 배열, 반복문, 집합의 역할을 대략 알고 있다고 가정해요.

## 새 용어 정의
- **정점**: 그래프에서 위치를 나타내는 점이에요.
- **방향 간선**: 한 정점에서 다른 정점으로만 이동하는 연결이에요.
- **가중치**: 그 간선을 지날 때 더하는 비용이에요.
- **거리 후보**: 지금까지 발견한 경로로 계산한 임시 비용이에요.
- **확정**: 아직 확정하지 않은 정점 중 거리가 가장 작은 정점을 선택해, 그 값이 최단임을 고정하는 일이에요.
- **relaxation**: 현재 정점을 거쳐 가는 후보가 더 작으면 거리와 parent를 갱신하는 일이에요.

## 관찰 가능한 학습목표
학습자는 작은 방향 그래프에서 array scan 다익스트라를 손으로 한 단계씩 추적하고, 확정 시점에만 멈추며, 경로·비용·parent를 Python과 C++17로 재현할 수 있어요.

## 고정 실행 계약
- 기본 그래프: A→B 가중치 4, A→C 가중치 1, C→B 가중치 2, C→D 가중치 5, B→D 가중치 1. E는 고립돼요.
- 시작 A, 목표 D의 답은 A→C→B→D, 비용 4예요. A→B→D는 5, A→C→D는 6이라 BFS의 간선 수 기준과 달라요.
- 미확정 정점 배열을 매번 훑어 최소 거리를 고르고, 구현 복잡도는 O(V^2+E)예요. 오늘은 heap 최적화를 하지 않아요.
- 가중치는 0 이상 정수만 받아요. 0은 무한대가 아니라 실제 비용 0이고, 무한대는 JSON에서 null로 기록해요.
- 같은 후보는 strict improvement만 허용해 기존 parent를 유지하고, 선택 동률은 정점 이름의 사전순으로 처리해요.
- 목표를 처음 발견한 순간이 아니라 목표가 확정된 순간에만 조기 종료해요.
- 음수 가중치는 입력 단계에서 거절해요. 음수 그래프의 정당성 증명과 Bellman-Ford는 범위 밖이에요.

## 예측과 전이
1. 0 가중치, 도달 불가 E, 시작과 목표가 같은 경우를 실제 실행해요.
2. A→B와 A→C가 같은 비용인 tie에서 먼저 정해진 parent를 유지하는지 예측해요.
3. C→D를 1로 바꾼 전이 입력을 다시 실행해 A→C→D, 비용 2가 되는지 확인해요.

## 수업 종료 기준
- 화면의 모든 거리·parent·확정 집합은 canonical trace의 한 시점 snapshot이에요.
- snapshot을 복사하는 계측 비용은 알고리즘 복잡도와 별도라고 구분해요.
- 독립 검수, 음성 듣기, 렌더 픽셀 검수와 학습 효과 측정은 이 source 단계에서 하지 않아요.
