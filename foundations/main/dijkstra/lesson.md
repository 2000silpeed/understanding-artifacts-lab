# 다익스트라: 확정된 거리부터 넓혀 가기

이 수업은 **음이 아닌 가중치**를 가진 방향 그래프에서 한 출발점으로부터 목표까지 가는 최소 비용을 찾는 방법을 다뤄요. 간선 개수가 아니라 가중치 합을 비교하므로, 간선 수가 적은 길이가 항상 싼 길이는 아니에요.

## 먼저 읽는 약속
정점은 A, B, C, D, E예요. 기본 방향 간선은 A에서 B로 4, A에서 C로 1, C에서 B로 2, C에서 D로 5, B에서 D로 1이에요. E는 고립돼요. 시작은 A, 목표는 D예요.

거리는 세 종류로 보여요. 아직 후보가 없으면 무한대라서 JSON의 `null`로 기록하고, 숫자 0은 실제로 비용이 0인 상태예요. `parent`는 그 거리를 만들었던 바로 이전 정점을 기억해 경로를 복원해요.

## 핵심 원리
1. 아직 확정하지 않은 정점 중 거리 후보가 가장 작은 정점을 array scan으로 선택해요.
2. 그 정점을 확정해요. 목표라면 이제 멈춰도 돼요.
3. 그 정점에서 나가는 각 방향 간선을 relaxation해요. `현재 거리 + 가중치`가 기존 후보보다 작을 때만 후보와 parent를 바꿔요.
4. 같은 값이면 바꾸지 않아요. 선택이 같은 경우에는 정점 이름 사전순으로 골라 실행 결과를 고정해요.

기본 입력에서 A를 확정하면 B 후보는 4, C 후보는 1이에요. C를 확정한 뒤 B는 3으로 개선되고, D는 6이에요. 이어서 B를 확정하면 D가 4로 개선돼요. D를 확정할 때 A→C→B→D, 비용 4가 완성돼요.

## 코드와 경계
Python과 C++17 예제는 같은 입력과 같은 event snapshot을 출력해요. 최소값 선택은 단순 배열 scan이라 O(V^2+E)이고, 화면에 남기는 snapshot은 거리·parent·확정 집합을 복사하는 별도 계측 비용이에요. heap 기반 최적화는 오늘 구현하지 않아요.

0 가중치에서는 숫자 0을 정상 후보로 처리하고, E 같은 도달 불가 정점은 끝까지 무한대예요. 시작과 목표가 같은 경우는 시작 정점을 확정하는 즉시 비용 0으로 끝나요. 음수 가중치는 이 알고리즘의 전제가 아니므로 입력을 거절해요.

목표를 처음 발견했다고 멈추면 안 돼요. 더 싼 경로가 나중에 발견될 수 있기 때문이에요. 목표가 **확정**된 순간에만 멈추는 경계를 지켜야 해요.

## 전이 질문
C에서 D로 가는 비용을 5에서 1로 바꾸면 어떻게 될까요? 실제 실행에서는 A→C→D, 비용 2가 나와요. 입력이 바뀌어도 최소 미확정 거리 선택, strict improvement, 확정 후 조기 종료라는 약속은 그대로예요.
