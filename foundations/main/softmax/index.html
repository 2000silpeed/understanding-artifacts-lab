점수에서 확률로

공개 임베딩 [0, 2]와 손으로 고른 W로 logits를 만들고, max subtraction을 거친 stable softmax를 직접 다시 계산해요. class는 토큰 후보, weight는 exp 뒤의 양수 가중치, shape는 행과 열의 크기예요.

계약: embedding × W

입력은 [0, 2], W = [[1, 0, −1], [0, 1, 2]]이며 셰이프는 2×3이에요. 이 표는 학습된 모델 가중치가 아닌 toy matrix예요.

소수 여섯 자리로 표시한 확률의 합은 반올림 때문에 0.999999가 될 수 있어요. 표시 전 부동소수점 정규화 합과 구분해요.

핵심 코드

def stable_softmax(logits):
    peak = max(logits)
    shifted = [z - peak for z in logits]
    weights = [math.exp(z) for z in shifted]
    denominator = sum(weights)
    return [w / denominator for w in weights]
negative shifted score는 허용되지만 exp 뒤 weight와 probability는 양수예요. max를 빼면 큰 양의 지수 overflow 위험을 줄여요. 이 페이지는 의미 이해나 Transformer 추론을 시연하지 않아요.

이 수업의 목적

앞 수업에서 공개된 임베딩 조회 결과를 입력으로 사용해요. 임베딩은 토큰을 숫자 벡터로 표현한 값이고, 이번 입력은 [0, 2]예요. 오늘은 이 벡터가 가중치 행렬과 곱해져 점수가 되고, 그 점수가 확률로 바뀌는 과정을 초보자도 다시 계산할 수 있도록 설명해요.

수업이 끝나면 다음을 할 수 있어요.

  1. 입력 벡터 [0, 2]와 가중치 행렬 W의 행과 열을 읽어요.
  2. 행렬 곱으로 세 후보의 점수 logits = [0, 2, 4]를 직접 계산해요.
  3. 가장 큰 점수를 빼는 stable softmax의 이유를 설명해요.
  4. exp가 만드는 양수 가중치, 분모, 확률을 실제 숫자로 확인해요.
  5. Python과 C++17 코드가 같은 중간값과 결과를 내는지 확인해요.
  6. 표시된 소수의 합과 표시 전 부동소수점 계산의 합을 구분해요.

선수 개념과 범위

선수 개념은 직전 공개 수업에서 다룬 임베딩 조회예요. 그 수업에서 토큰 하나를 숫자 벡터로 바꾸는 표를 읽고 [0, 2]를 얻었다고 가정해요. 이 lesson은 그 조회 표를 다시 학습하거나 의미를 해석하지 않고, 이미 나온 벡터를 다음 계산에 넣어요.

이번 예시는 손으로 고른 작은 행렬을 쓰는 toy example이에요. 실제 학습된 모델의 가중치, Transformer 추론, 의미 이해, loss, temperature, top-p를 설명하는 수업이 아니에요. 목적은 점수에서 확률로 가는 숫자 규칙을 투명하게 따라가는 거예요.

용어를 먼저 정리해요

  • 토큰 후보와 class: 모델이 고를 수 있는 토큰 후보 하나를 class라고 부를 수 있어요. 여기서는 후보 a, b, c 세 개가 있고, 각 후보에 점수 한 칸씩 있어요.
  • logit: 아직 확률이 아닌 원점수예요. 후보끼리 어느 쪽이 큰지 비교할 때 사용해요.
  • 가중치와 weight: 입력 성분을 각 점수에 얼마나 반영할지 정하는 수예요. exp 뒤에 나오는 weight는 항상 양수인 가중치예요.
  • 셰이프 shape: 표의 행 개수와 열 개수를 함께 말하는 크기예요. 2×3은 행 둘과 열 셋이라는 뜻이에요.
  • max: 여러 값 중 가장 큰 값인 최댓값이에요. stable softmax에서는 이 최댓값을 모든 점수에서 빼요.
  • sum: 값들을 빠짐없이 모두 더한 합이에요. softmax의 분모는 모든 양수 weight의 sum이에요.
  • exp: 자연 지수 함수예요. 입력이 커질수록 값이 빠르게 커지는 함수라서, 점수의 순서를 보존하면서 양수 값을 만들어요.
  • 정규화: 여러 양수 값을 그 합으로 나누어 전체가 한 분포가 되도록 만드는 과정이에요.

실행 가능한 숫자 계약

입력 벡터와 행렬은 다음과 같아요.

x = [0, 2]
W = [[1, 0, -1],
     [0, 1,  2]]
W shape = [2, 3]

행렬의 각 열을 입력 벡터와 곱해 더하면 세 점수가 나와요.

logits = [0×1 + 2×0,
          0×0 + 2×1,
          0×(-1) + 2×2]
       = [0, 2, 4]

가장 큰 점수는 4예요. stable softmax는 큰 양의 수를 그대로 지수화하지 않고 다음처럼 바꿔요.

shifted = logits - max(logits) = [-4, -2, 0]
weight_i = exp(shifted_i)
denominator = sum_j exp(shifted_j)
probability_i = weight_i / denominator

실제 값은 exp(-4), exp(-2), exp(0)에서 나온 양수 weight 세 개, 분모 1.153651..., 확률 [0.015876..., 0.117310..., 0.866813...]이에요. 출력은 비교를 위해 소수점 아래 여섯 자리로 표시하지만, 표시된 세 확률을 더하면 0.999999가 돼요. 표시 전 부동소수점 정규화 합은 별도로 출력해요. 따라서 반올림된 표시값의 합을 정확히 1이라고 말하지 않아요.

예측과 전이 질문

가장 큰 확률을 가진 후보의 위치가 예측이에요. 이 예시에서는 세 번째 후보, 인덱스 2가 선택돼요. 중간에 예측을 먼저 생각하는 구간을 두고, 정답은 reveal cue 뒤에 보여 줘요.

전이 질문에서는 세 logits가 모두 같다고 가정해요. 그러면 세 exp weight도 같고, 같은 분모로 나누므로 각 확률은 1/3이에요. 이 결론은 표시 소수의 합에서 추측하는 것이 아니라, 세 항이 대칭이라는 이유에서 나와요.
