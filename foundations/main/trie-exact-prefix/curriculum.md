# 오늘의 DS 신규 트라이: 트라이에서 정확 검색과 접두사 검색

## 대상과 선행지식
- 배열과 문자열을 읽고, 반복문으로 한 글자씩 처리할 수 있는 초보 학습자예요.
- 노드와 간선이라는 그래프의 기본 낱말을 처음부터 정의해요.

## 관찰 가능한 학습목표
수업이 끝나면 학습자는 `car`, `cat`, `dog`를 넣은 트라이에서 정확 검색과 접두사 검색을 구분하고, `ca`를 단어로 삽입한 뒤에도 `car`와 `cat`이 보존되는 이유를 코드와 이벤트 snapshot으로 설명할 수 있어요.

## 고정 실행 계약
- 입력은 영어 소문자 `a-z`만 허용하고, 빈 문자열은 거절해요.
- 기본 단어는 `car`, `cat`, `dog`예요.
- `exact("car")`는 참, `exact("ca")`는 거짓, `prefix("ca")`는 참, `exact("cap")`는 거짓이에요.
- `insert("ca")` 뒤에는 `exact("ca")`가 참이 되지만 기존 `car`, `cat`은 그대로 참이에요.
- 같은 단어를 다시 삽입해도 노드와 terminal 상태는 바뀌지 않아요.
- 전이 예제 `do`는 삽입 전 exact는 거짓이고, 삽입 뒤 exact와 prefix가 참이며 기존 `dog`도 참이에요.
- 각 문자 follow/create와 terminal 검사는 한 시점의 상태를 event snapshot에 기록해요.

## 수업 흐름
정의 → `car`, `cat`, `dog`의 공유 경로 → exact와 prefix 결과 예측 → 실제 삽입·검색 코드 → 빈 문자열과 대문자 경계 → `do` 전이 실행 → 복잡도와 한계 요약.

## 범위 밖
삭제, 자동완성 순위, 한글 분절, 정규화, 대소문자 변환은 구현하지 않아요. 고정 알파벳 배열 child 조회를 가정하며 노드마다 26개 슬롯을 둘 수 있다는 메모리 비용과 화면용 snapshot 복사 비용은 별도로 말해요.
