# 교안: 트라이, 같은 앞부분을 공유하는 문자열 구조

## 1. 질문과 핵심 낱말
문자열 `car`와 `cat`을 모두 저장할 때 `ca`를 두 번 저장할 필요가 있을까요? 트라이는 문자열을 문자 단위 노드와 간선으로 나누고, 공통 앞부분인 접두사의 경로를 공유해요. 루트는 빈 시작점이고, 노드는 한 문자와 다음 문자로 가는 child 연결을 가질 수 있어요. 단어가 여기서 끝난다는 표시는 `terminal`이에요.

## 2. 작은 예
`car`, `cat`, `dog`를 차례로 넣으면 `c`와 `a` 경로는 공유하고, 세 번째 문자 `r`과 `t`에서 갈라져요. `ca` 경로가 존재한다는 사실만으로 `ca`가 완성된 단어라는 뜻은 아니에요. 따라서 `exact("ca")`는 거짓이고 `prefix("ca")`는 참이에요. `exact("cap")`은 `p` child가 없어서 거짓이에요.

## 3. 정확 검색과 접두사 검색
정확 검색은 모든 문자를 따라간 뒤 마지막 노드의 terminal을 확인해요. 접두사 검색은 모든 문자를 따라가는 데 성공하면 terminal을 요구하지 않고 참을 돌려줘요. 이 차이 때문에 중간 경로와 완성 단어 표시를 분리해서 그려야 해요.

## 4. 삽입의 보존 규칙
`ca`를 새로 삽입하면 이미 있는 `c → a` 노드를 재사용하고, `a` 노드의 terminal만 참으로 바꿔요. 그래서 `car`와 `cat`의 뒤쪽 경로는 손상되지 않아요. 같은 `ca`를 한 번 더 넣으면 이미 terminal이 참이므로 상태가 그대로예요.

## 5. 코드와 경계
Python과 C++ 구현은 매 문자마다 고정 배열의 child 슬롯을 조회하거나 만들어요. 그래서 문자열 길이를 `L`이라고 할 때 검색과 삽입은 `O(L)`이에요. 실제 노드마다 26개 슬롯을 준비하는 메모리와 화면용 snapshot을 복사하는 계측 비용은 이 계산과 별도로 봐요. 빈 문자열과 소문자 밖 입력은 명시적으로 거절해요.

## 6. 예측과 전이
기본 단어 집합에서 `ca`를 exact 검색하면 무엇이 나올까요? 먼저 경로는 있지만 terminal은 없다는 답을 생각하고, 공개 cue 뒤 실제 결과를 확인해요. 이어서 `do`를 삽입하면 `d → o` 경로가 새로 생기고 `dog`의 `d → o → g`는 그대로 남아요. 자료구조의 핵심은 공통 경로를 공유하면서 terminal 경계를 따로 보존하는 거예요.
