임베딩 조회: ID로 행 고르기

어휘 a=0, b=1, c=2를 3×2 표 E의 행과 연결합니다. ID로 행을 고르는 것과 one-hot 벡터로 행을 곱해 더하는 것이 같은지 확인해 봅시다.

임베딩 표 E · 3행 × 2열 (각 셀 -100~100)

ID 0 (a)ID 1 (b)ID 2 (c)

입력을 바꾸면 이전 결과를 새 입력으로 즉시 다시 계산하고 첫 단계로 돌아갑니다. 음수·범위 밖·소수 ID는 오류입니다.

한 ID: 선택 → 곱하기 → 더하기

시퀀스: 각 ID를 같은 표에서 조회
예제
ID 1은 one-hot [0,1,0]입니다. 가중 행 [[0,0],[0,2],[0,0]]을 더하면 [0,2], 곧 E[1]입니다. 시퀀스 [0,1,0,2]는 [[1,0],[0,2],[1,0],[-1,1]]입니다. 출력은 길이 4 × 차원 2, 즉 4×2입니다. 어휘 크기 3과 시퀀스 길이 4를 구분하세요.
연산과 비용
직접 조회는 행 선택 후 차원 d개의 값을 읽습니다(O(d)). 여기서 표시하는 one-hot 곱셈·합은 어휘 크기 V에 대해 O(Vd)인 교육용 계산입니다. 실제 조회에 굳이 one-hot 전체를 만들 필요는 없습니다.
이 표는 손으로 고른 숫자이며 학습된 모델이 아닙니다. 숫자 사이의 거리가 의미 유사성의 증거는 아닙니다. 이 실험은 실제 LLM 추론을 수행하지 않습니다.
도전
E의 0행을 바꾸세요. 시퀀스에서 두 번 등장하는 ID 0의 출력이 함께 바뀌나요? ID -1, 3, 1.5를 넣어 오류를 확인한 뒤 1로 되돌리세요.
