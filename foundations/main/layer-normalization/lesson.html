레이어 정규화: 한 토큰의 특징을 맞추기

오늘의 목표
아래 네 값을 계산해서 평균·분산·정규화 값의 관계를 읽습니다. 첫 행동은 값을 확인하고 계산하기를 누르는 것입니다.

1. 직접 계산

입력은 토큰 하나의 벡터입니다. 기본 ε은 0.00001이고, 분산은 d로 나눕니다.

2. 왜 이렇게 되나요?

먼저 토큰 하나 안의 특징 축으로 μ와 편향 분산 σ²를 구합니다. 평균을 빼서 중심을 0에 맞추고 √(σ²+ε)로 나눕니다. 입력에 같은 상수를 더해도 정규화 값은 같고, 양수 배율로 키우면 ε의 영향이 작을 때 정규화 값은 거의 같습니다.

μ = Σx / d ··· σ² = Σ(x−μ)² / d ··· x̂ = (x−μ) / √(σ²+ε) ··· y = γx̂+β

ε은 0으로 나누는 일을 막기 위해 제곱근 안에 더합니다. 모든 값이 같으면 σ²=0이고, ε 덕분에 x̂는 모두 0이 됩니다. 이는 분산이 1이라는 뜻이 아닙니다.

배치 정규화와 달리 고정된 토큰 벡터의 LayerNorm 결과는 다른 토큰과 독립입니다. 다만 앞단에서 만든 은닉 벡터 자체가 다른 토큰/어텐션의 영향을 받을 수 있다는 뜻까지 부정하지는 않습니다.

3. 예측하고 확인

정규화 전 입력을 [2, 4, 6, 8]에서 모두 같은 값 [5, 5, 5, 5]로 바꾸면, x̂의 네 값은 어떻게 될까요?

정답: 0에 가깝다.
모든 값이 평균과 같아 각 (x−μ)가 0입니다. ε은 분모를 안전하게 만들 뿐, 상수 입력의 분산을 1로 바꾸지 않습니다.

정의 → 예제 → 실제 코드

정의: LayerNorm은 각 토큰의 마지막 특징 축을 평균 0·분산 1에 가깝게 맞추는 연산입니다(ε과 affine 때문에 정확히는 조건부 표현).

예제: [2,4,6,8]은 μ=5, σ²=5이고, ε을 넣은 분모로 x̂를 만듭니다.

실제 코드: 동봉된 Python/C++ 예제는 d로 나누는 편향 분산과 같은 덧셈 순서를 사용합니다. 모델의 모든 내부 벡터를 뜻하는 제품 로그가 아니라, 개념을 보여 주는 작은 입력입니다.

한계: gamma와 beta는 특징별 학습 파라미터이며, 실제 모델의 앞단·잔차·어텐션 구성은 이 장난감 예제보다 큽니다.
