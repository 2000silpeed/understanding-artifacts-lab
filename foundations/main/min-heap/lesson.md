# 최소 힙: 가장 작은 값을 빠르게 꺼내기

이 수업은 먼저 들어온 순서가 아니라 값의 크기로 최솟값을 찾는 문제에서 시작해요. 최소 힙은 마지막 층을 왼쪽부터 채우는 완전 이진 트리이고, 모든 부모 값이 자식 값보다 작거나 같다는 약속을 가집니다. 그래서 루트가 현재 최솟값이에요.

배열로 저장하면 부모와 자식 위치를 계산할 수 있어요. 인덱스 `i`의 부모는 `(i-1)//2`, 왼쪽 자식은 `2*i+1`, 오른쪽 자식은 `2*i+2`예요. 부모 규칙은 형제끼리의 순서나 전체 오름차순을 보장하지 않아요.

새 값을 맨 뒤에 붙이고 부모와 비교해 더 작으면 위로 교환해요. 최솟값을 꺼낼 때는 마지막 값을 루트로 옮긴 뒤 더 작은 자식과 비교하며 아래로 교환해요. 이 수업의 모든 중간 상태는 수동 Python과 C++17 실행에서 나온 trace예요. `heapq`나 `priority_queue`는 핵심 구현에 사용하지 않았어요.

맨 뒤 추가는 배열 확장 때문에 별도 비용이 생길 수 있고, 힙 복구는 높이에 비례해 `O(log n)`이에요. `peek`은 루트만 읽으므로 `O(1)`이에요. 전체 snapshot을 JSON으로 남기는 비용은 알고리즘 비용과 구별되는 계측 오버헤드예요.

source test는 실제 Python·C++17 실행, stdout과 trace parity, 실제 parser와 Stage proxy, offline HTML, 그리고 이 수치 계약을 점검해요. 이 source PASS는 사람의 독립 검수, TTS, 렌더, 픽셀 검수, 게시 승인을 뜻하지 않아요.

## 실행과 직접 확인
```sh
python3 canonical.py
python3 canonical.py --trace
g++ -std=c++17 canonical.cpp -o /tmp/lesson-ds
/tmp/lesson-ds --trace
```

`script.md`는 용어 정의부터 두 연산의 코드 설명, 예측, 경계와 비용 구분까지의 전체 교사 대본이에요. 실제 수동 리스트 코드는 `canonical.py`에서 읽고, 화면 발췌 `code-shared.js`는 연속된 원문과 동일한지 검사해요.

루트는 맨 위, 부모는 바로 위, 자식은 바로 아래 점이에요. 층은 같은 높이의 점들이며 마지막 층을 왼쪽부터 채워요. 인덱스는 0부터 세고 부모 계산의 몫은 소수 부분을 버린 정수예요.

push3의 비교는 (6,2)의 3과7, 이어 (2,0)의 3과4예요. pop3은 [7,9,4,15,12,10]을 거쳐 [4,9,7,15,12,10]이 돼요. [1,2,3]의 pop은 오른쪽 없이 [3,2]에서 [2,3]으로 가요. 중복과 빈 힙, 한 원소 실행은 trace의 edges에서 확인해요.

공간 확장 한 번은 O(n)일 수 있으며 append는 분할 상환 O(1), 논리 복구는 O(log n)이에요. 크기 n의 전체 snapshot 한 번은 O(n)이므로 추적을 포함한 프로그램 전체가 O(log n)이라고 해석하면 안 돼요.
