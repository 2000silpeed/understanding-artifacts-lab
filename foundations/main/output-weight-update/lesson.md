# 출력 가중치 행렬의 수동 업데이트

## 한 문장 요약
앞에서 배운 `g = p - y`를 출력 로짓에 직접 적용하는 대신, 입력 표현 `h`와 곱해 출력 가중치 행렬 `W` 전체의 기울기 `dW = h ⊗ g`를 만든다.

## 핵심 예
입력 `h=[1,2]`, `W`는 이 곱하기 삼 영행렬, 정답 아이디는 2, 학습률은 0.3이다. 처음에는 `z=[0,0,0]`, `p=[1/3,1/3,1/3]`, `g=[1/3,1/3,-2/3]`이다. 따라서

`dW=[[1/3,1/3,-2/3],[2/3,2/3,-4/3]]`

이고 `W'=[[-0.1,-0.1,0.2],[-0.2,-0.2,0.4]]`가 된다. 새 로짓은 `[-0.5,-0.5,1]`, 새 확률은 약 `[0.154281,0.154281,0.691438]`, 손실은 `1.098612`에서 `0.368981`로 내려간다.

## 한 가중치로 보는 이유
`z_j`에서 `W_ij`를 조금 바꾸면 변화량은 입력 성분 `h_i`에 비례한다. 같은 출력 방향 `g_j`라도 입력이 두 배인 둘째 성분은 기울기가 두 배다. 이것이 바깥 곱의 각 행에 나타난다.

## 검산과 전이
유한 차분으로 각 `W_ij`를 조금씩 양쪽으로 흔들어 손실 변화율을 계산한다. 수동 `dW`와 일치해야 한다. `h=[1,0]`이면 둘째 행은 0이지만, 새 입력에서 `z`, `p`, `g`를 다시 계산한다.

## 오해 방지
이 예는 한 샘플과 한 단계다. 전체 데이터 일반화, 임베딩 학습, 자동 미분, 트랜스포머 전체 학습을 뜻하지 않는다.
