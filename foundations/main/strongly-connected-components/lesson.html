강한 연결 요소 companion — 학습자용 안내

이 문서는 첫 화면에서 네 문제를 선택하고, 선택 직후 같은 화면에서 정답·오답의 이유를 확인한 뒤 다음 문제로 이동하는 연습의 수업 노트입니다.

원본에 맞춘 사실

  • 고정 예제는 서비스 호출 방향 그래프 8정점·11간선입니다.
  • Kosaraju의 1단계 끝난 순서: 포인트 인증 회원 알림 결제 주문 추천 검색
  • 2단계 살펴볼 순서: 검색 추천 주문 결제 알림 회원 인증 포인트
  • 묶음: {검색 추천}, {주문 포인트 결제}, {알림}, {회원 인증}
  • 호출받는 쪽 먼저 배포: 4 → 3 → 2 → 1
  • Python과 C++17 예제는 같은 출력 문자열을 냅니다.
원본 실행 결과의 묶음 번호는 발견 순서에 따라 붙습니다. 따라서 다른 구현의 번호를 절대적인 이름처럼 쓰지 않고, 이 companion은 정점 이름과 분할을 함께 보여 줍니다.

실행

index.html을 로컬 브라우저에서 열면 됩니다. 네트워크, 계정, 외부 글꼴, 추적 코드, 서버 API를 사용하지 않습니다.

downloads/scc-code.zip에는 원본에서 복사한 실행 가능한 Python/C++ 입력과 코드가 들어 있습니다. ZIP 밖의 source/는 읽기 쉬운 원본 사본과 실행 결과입니다.

예제 실행(압축을 푼 뒤 코드 폴더에서):

python3 examples/python/scc.py examples/fixtures/services.graph
c++ -std=c++17 -O2 -Wall -Wextra -Werror examples/cpp/main.cpp -o /tmp/scc
/tmp/scc examples/fixtures/services.graph

범위와 한계

이 패키지는 결정적인 예제와 UI 상호작용을 검증합니다. 사람의 실제 학습 효과, 접근성 보조기기 사용성, 영상 청취, 배포 상태는 측정하지 않았습니다(NOT_MEASURED). 영상·유료 제공자·게시·로그인 동작은 이 stage의 범위가 아닙니다.
