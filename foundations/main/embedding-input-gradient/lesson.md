# 임베딩 입력 행 업데이트

## 한 문장 요약
출력 오차 `g`가 고정된 출력 행렬 `W`를 거꾸로 통과하면, 조회된 임베딩 행 하나의 변화량 `dh`가 되고 그 행만 업데이트돼요.

## 문제를 작게 고정하기
이번에는 토큰 ID `1`을 입력해요. ID `1`은 0부터 번호를 세었을 때 두 번째 행을 뜻하므로 `E[1]=[1,2]`가 입력 벡터 `h`가 돼요. 임베딩 표는 다음과 같아요.

`E=[[0,1],[1,2],[-1,1]]`

출력 행렬 `W`는 앞 수업의 한 단계 뒤 결과를 그대로 고정해요.

`W=[[-0.1,-0.1,0.2],[-0.2,-0.2,0.4]]`

정답 ID는 `2`, 학습률은 `0.3`이에요. ID `2`는 세 번째 출력 칸이며, 숫자 2라는 값과 순서 두 번째를 혼동하면 안 돼요.

## 먼저 순방향을 다시 계산하기
행렬 곱으로 세 점수를 만들어요.

`z=hW=[-0.5,-0.5,1]`

소프트맥스를 적용하면 확률 `p`가 되고, 정답 ID `2`의 확률로 한 칸 손실을 계산해요. 코드와 trace가 계산한 표시값은 `p≈[0.154281,0.154281,0.691438]`, `loss≈0.368981`이에요. 여기서 표시 소수는 읽기 위한 반올림이며, 계산은 더 긴 실수로 진행해요.

정답 벡터 `y`는 ID `2` 칸만 `1`이고 나머지는 `0`이에요. 그래서 출력 점수의 기울기는 `g=p-y`가 돼요. 정답 칸에서는 `0.691438-1`이므로 음수예요. 이 부호는 정답 점수를 더 키우는 업데이트가 손실을 줄이는 방향임을 알려 줘요.

## 새 핵심: 입력 쪽으로 돌아오기
각 입력 성분 `i`에 대한 변화량은 출력 칸 전체의 영향을 더해 계산해요.

`dh_i = Σ_j W[i][j] × g_j`

즉 `W`의 첫 번째 행과 `g`를 곱해 `dh[0]`을 만들고, 두 번째 행과 `g`를 곱해 `dh[1]`을 만들어요. 이번 숫자에서는 두 값이 실제 계산으로 각각 `≈-0.092568`, `≈-0.185137`이에요. 둘째 입력 성분의 행이 첫째 행의 두 배였기 때문에 변화량도 두 배가 돼요. 기울기가 음수라서 빼기 업데이트 뒤의 `E[1]`은 커져요.

토큰 ID `1`이 선택한 행은 `E[1]`이에요. 따라서 `dE`는 선택 행에만 `dh`를 놓고 나머지는 0으로 둬요. 업데이트는 `E[1]'=E[1]-0.3×dh`예요. `E[0]`과 `E[2]`는 이번 샘플의 조회 행이 아니므로 그대로 남아요. `W`도 고정해요.

업데이트한 입력을 같은 고정 `W`에 다시 넣으면 `h'`, `z'`, `p'`, `loss'`를 비교할 수 있어요. 입력 벡터가 달라졌으므로 새 순방향 결과도 다시 계산해야 해요. 이 한 단계의 손실 변화가 전체 데이터의 학습 효과를 보장하지는 않아요.

## 예측하고 검산하기
질문 전에 화면에 입력 행, `W`, `g`의 피연산자를 계속 남겨요. 먼저 `dh`의 부호와 업데이트 결과를 적어 보세요. 답은 잠시 뒤 계산으로 공개해요.

그 다음 `E[1]`의 각 성분을 `epsilon`만큼 올리고 내린 두 손실의 차이를 `2epsilon`으로 나눠요. 이 중앙 유한 차분이 수동으로 구한 `dh`와 가까워야 해요. 이것은 이 toy 계산의 수치 검산이지, 자동 미분을 사용했다는 뜻이 아니에요.

경계도 중요해요. `W`를 영행렬로 실행하면 출력 오차 `g`가 어떻든 `W[i][j]×g[j]`가 모두 0이므로 `dh=[0,0]`이에요.

## 입력 ID를 바꾸는 전이
입력 ID `0`으로 바꾸면 조회 행은 `E[0]=[0,1]`이에요. 이제 `h`가 달라졌으므로 `z`, `p`, `loss`, `g`, `dh`를 다시 계산해야 해요. 기본 입력에서 바뀐 `E[1]`을 사용하더라도 ID `0`의 행 자체는 바뀌지 않아요. 조회된 한 행만 업데이트된다는 규칙이 실제 전이에서도 유지돼요.
