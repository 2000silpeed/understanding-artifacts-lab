# 학습 설계: 임베딩 입력 행 업데이트

## 수업 제목
임베딩 입력 행 업데이트: 출력 오차가 입력 표의 한 행으로 돌아오는 과정

## 선행 지식
- 벡터와 행렬의 행·열, 행렬 곱을 읽을 수 있어요.
- 입력 벡터 `h`와 출력 행렬 `W`로 로짓 `z`를 계산해 봤어요.
- 로짓을 소프트맥스 확률로 바꾸고, 정답 확률의 음의 로그 손실을 구해 봤어요.
- 출력 쪽 로짓 기울기 `g = p - y`와 출력 행렬 업데이트를 앞 수업에서 봤어요.

## observable objective
수업을 마친 학습자는 다음을 실제 숫자로 설명하고 계산할 수 있어요.

1. 토큰 ID `1`이 임베딩 표 `E`의 두 번째 행 `E[1]`을 선택하고, 그 행이 `h=[1,2]`가 됨을 구분해요. ID는 0부터 세며, ID `1`은 순서 첫 번째가 아니에요.
2. 고정된 `W`에서 `z=hW`, 소프트맥스, NLL, `g=p-y`를 다시 계산해요.
3. 입력 임베딩 행의 기울기를 `dE[1]_i = dh_i = Σ_j W[i][j] × g[j]`로 계산하고, 선택된 행만 `E[1]' = E[1] - lr × dh`로 업데이트해요.
4. 선택되지 않은 `E[0]`, `E[2]`가 그대로인 이유를 말해요. 이번 단계에서는 `W`를 함께 업데이트하지 않아요.
5. 중앙 유한 차분으로 `dh`를 검산하고, `W=0`이면 `dh=0`이 되는 경계를 확인해요.
6. 입력 ID `0` 전이에서 새 `h`, `z`, `p`, `g`를 다시 계산해요. 한 행의 변화가 모든 입력을 바꾸는 것은 아님을 말해요.

## 고정 수치 계약
- `W=[[-0.1,-0.1,0.2],[-0.2,-0.2,0.4]]`는 고정해요.
- `E=[[0,1],[1,2],[-1,1]]`의 각 행은 ID `0`, ID `1`, ID `2`에 대응해요.
- 기본 입력은 token ID `1`이므로 `h=E[1]=[1,2]`예요.
- 정답 ID는 `2`, 학습률은 `0.3`이에요.
- `z_j = Σ_i h_i W[i][j]`, `p=softmax(z)`, `loss=-ln(p[target])`예요.
- `g_j=p_j-y_j`, 여기서 `y[2]=1`이고 나머지는 `0`이에요.
- `dh_i=Σ_j W[i][j]g_j`예요. 선택된 입력 행만 `dE[1]=dh`로 놓아요.
- `E' = E`로 시작해 `E'[1] = E[1] - 0.3 dh`만 바꿔요. `W`는 고정이에요.

## 예측과 전이
- 예측: `dh`의 두 성분 부호와 `E[1]'`의 두 성분을 먼저 계산해요.
- 검산: 각 `E[1]` 성분을 작은 `epsilon`만큼 양쪽으로 흔들어 손실의 중앙 차분을 구해요.
- 경계: `W`를 영행렬로 바꾸면 모든 `dh`가 0이에요. 이 경계는 별도 실행값으로 확인해요.
- 전이: 입력 ID `0`을 실제로 넣어 `h=E[0]=[0,1]`을 만들어요. 같은 고정 `W`에서 `z,p,g,dh`를 새로 계산하고, 기본 입력의 업데이트 결과를 ID `0`에 적용한 경우도 보여 줘요.

## 범위 경계
이 수업은 한 toy lookup 표에서 한 샘플을 한 번 업데이트하는 수동 계산이에요. 자동 미분, 프레임워크, 편향, 여러 샘플 평균, 전체 학습 루프, 어텐션, 트랜스포머의 전체 학습은 구현하거나 주장하지 않아요. `dh`는 이 선형 toy 경로에서의 입력 쪽 변화율을 계산하는 방법으로 설명하며, 도함수의 완전한 증명이라고 말하지 않아요.

## 학습자에게 남길 답
기본 입력 ID `1`에서는 `E[1]`만 바뀌고 `E[0]`, `E[2]`는 그대로예요. `W`가 0이면 입력값과 관계없이 `dh=0`이에요. 입력 ID `0`으로 바꾸면 선택 행과 `h`가 달라지므로 `z`, `p`, `g`, `dh`를 다시 계산해야 해요. 한 샘플의 손실 변화는 전체 데이터 성능이나 임베딩의 일반화를 보장하지 않아요.
