F는 언제 방문 표시가 되고, 언제 target을 찾았다고 선언될까요?

    

    

    
방문 표시는 E가 F를 push하는 순간, 성공은 F를 pop하는 순간입니다. 두 event 경계는 다릅니다.

  

  
핵심 약속
  • 스택 배열은 왼쪽이 bottom, 오른쪽이 top입니다.
  • 방문 표시는 push 때라서 중복 push와 cycle 반복을 막습니다. 명시적 스택은 선택한 새 형제들을 먼저 표시하고 push하므로 발견 순서는 재귀 DFS와 다를 수 있습니다.
  • 탐색 자체는 O(V+E)이며 이 그래프는 무방향 간선 6쌍, 인접 리스트 항목 12개입니다. 전체 snapshot 기록은 별도 계측 비용입니다.
  • DFS parent 경로는 일반적으로 최단 경로가 아닙니다.
