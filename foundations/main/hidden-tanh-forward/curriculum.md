# 누적 수업 설계: 은닉층 하나 추가하기

## 선행 지식
- 토큰 아이디로 임베딩 표의 행을 조회한다.
- 두 임베딩을 문맥 벡터로 이어 붙이면 모양이 `1×4`가 된다.
- 행렬 곱은 행과 열의 대응 원소를 곱해 더한다.
- 로짓은 점수이고, 안정적인 소프트맥스는 점수를 확률로 바꾼다.

## 이번 수업의 첫 정의
- **은닉층**: 최종 출력 전에 입력을 다시 섞어 중간 표현을 만드는 층.
- **편향**: 입력과 별개로 각 출력 칸에 더하는 값.
- **탄젠트 하이퍼볼릭**: 각 값을 마이너스 일과 일 사이로 눌러 주는 비선형 함수. 영은 영, 일은 약 영점칠육일오구사, 이는 약 영점구육사영으로 바뀐다.
- **순방향 계산**: 입력에서 출력까지 값을 한 방향으로 계산하는 과정.

## 관찰 가능한 학습 목표
학습자는 `[a,b]`, `[b,a]`, `[c,a]`를 직접 계산해 `x → u → h → z → p`의 각 모양과 값을 설명하고, 첫 층의 두 출력에 대한 실제 내적을 써 보며, 편향을 바꾸면 중간 합이 바뀐다는 것을 확인한다.

## 수업 흐름
1. 어제의 두 토큰 연결을 짧게 복습한다.
2. 은닉층, 편향, 탄젠트 하이퍼볼릭을 표와 작은 수로 정의하고 `0→0`, `1→0.761594`, `2→0.964028`을 확인한다.
3. 고정된 `W1`, `W2`와 영 편향으로 두 내적을 먼저 계산한 뒤 기본 순방향을 계산한다.
4. `[b,a]`를 예측하게 한 뒤 잠시 멈추고 결과를 공개한다.
5. 편향 사례와 `[c,a]` 전이 사례를 실행한다.
6. 선형층만 쌓는 경우와 탄젠트 하이퍼볼릭이 사이에 있는 경우를 비교한다.
7. Python, C++17, 오프라인 조작 웹에서 같은 계산을 재현한다.
8. 입력·은닉·출력 모양, 범위 밖의 항목을 회수한다.

## 질문과 실행 정답
- 질문: `[b,a]`의 은닉 표현은 `[a,b]`와 같은가? 정답: 아니며 위치가 바뀌어 `u`와 `h`가 바뀐다.
- 질문: `b1=[1,-1]`이면 `[a,b]`의 `u`는? 정답: `[1,0]`이다.
- 질문: `[c,a]`의 `u`는? 정답: `[2,0]`이다.
- 전이 정답: `h=[tanh(2),0]`, `z=[tanh(2),0,-tanh(2)]`이다.

## 범위 경계
학습된 가중치나 성능 향상을 주장하지 않는다. 역전파, 미분, 어텐션, 트랜스포머, 학습 루프는 다음 단계다. 이 수업의 숫자는 손으로 정한 장난감 가중치다.
