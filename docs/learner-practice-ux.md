# 학습자 실습 UX 기준

- 처음 방문한 학습자가 목표와 첫 행동을 설명서 없이 알 수 있게 한다. 예제 이름은 학습 상황으로 설명하고 파일명은 보조 정보로 둔다.
- 학습자의 판단 직후 정오와 이유, 실제 자료 및 결과의 변화를 함께 보여 준다. 오답에서도 안전하게 진행하고 다시 시도하거나 이전 상태로 돌아갈 수 있게 한다.
- 다음 행동은 실제 다음 질문으로 이어지며, 선택 전·피드백·완료 상태와 경계 버튼을 일관되게 표시한다. 관찰은 오답으로 채점하지 않는다.
- 모바일에서도 그림, 질문, 선택과 피드백을 가까이 배치한다. 키보드와 스크린리더로 사용할 수 있고 색상 외의 방법으로 정오를 알린다.
- 학습 노트는 읽기 쉬운 구조와 접을 수 있는 정답을 제공하고 원문과 실행 자료를 보존한다.
- 실제 브라우저에서 첫 방문부터 완료, 복구, 예제 변경과 키보드 조작을 확인하고 알고리즘 원본 결과를 보존한다.
