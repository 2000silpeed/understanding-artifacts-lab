# 실제 사람 평가 프로토콜 · 탐색용 파일럿

## 목적과 현재 상태
- 제작/회귀/디코드/AI 독립 검토와 사람의 청취·이해도를 별도 증거로 기록한다.
- 이 페이지는 실제 사람이 동의하고 답할 수 있는 도구다. 도구 실행 검사는 사람 참여가 아니다.
- 제출·검증된 사람 응답이 없으면 학습 효과/청취 인증은 **미측정**으로 남긴다. AI 답변·브라우저 QA fixture는 제외한다.

## 이해도 평가
- 대상: 한국어 기술 학습자. 이름·연락처·민감한 인구통계는 받지 않는다.
- 질문: 같은 핵심 개념을 글, 도식, 웹, 영상으로 설명할 때 새 입력에 대한 예측이 어떻게 달라지는가?
- 설계: 참여자 한 명에게 세 주제 중 하나와 네 형식 중 하나를 브라우저 crypto의 균등 무작위 배정으로 선택한다. 편향된 uint32 꼬리는 rejection sampling으로 제외한다.
- 같은 사람이 동일 주제를 네 번 보는 순서/반복 학습 오염을 피하려는 **between-participant 탐색 설계**다. 무작위 배정 자체가 충분한 표본·맹검·엄격한 인과효과 실험을 보장하지 않는다.
- 사전 3문항 → 자기 속도대로 한 형식 확인 → 변경된 예제의 사후 3문항 → 같은 기기에서 사후 완료 후 24시간 이상 지난 뒤 3문항 회상.
- 사전 단계에서는 정답을 보여주지 않는다. 정답 기준은 코드/JSON에 공개되어 있어 완전한 맹검이 아니다.
- 한 주제 안에서 형식별 사전/사후 정답 수와 단계별 벽시계 시간을 기술한다. 서로 다른 주제의 난이도를 같은 척도라 가정하여 합산 순위를 내지 않는다.
- 시간은 페이지 단계의 벽시계 시간이다. 집중 시간/읽기 시간/유효 시청 시간 인증이 아니다. 별도 시청 조건·동등한 노출 시간은 강제하지 않는다.
- 기존 자료 노출과 다른 형식 추가 노출을 기록한다. 회상 기간에 다른 자료를 본 여부도 기록한다.
- 문항의 평행성/난이도/타당도는 아직 사람에게 검증되지 않았다. 정답 수도 작아 천장/바닥/추측 효과가 크다. 표본 크기·효과 크기 추정과 검정력 설계 전에는 통계적 유의성·보편적 형식 우월성·인과적 학습 향상을 주장하지 않는다.
- 여러 형식 비교를 위해 이미 본 사람이 다시 참여하면 독립 참가자/새 학습으로 세지 않는다. 중복 ID의 마지막 export만 사용하며, 다른 ID로 반복 참여한 것을 자동 식별하지 못하는 한계가 있다.

## 자막·청취 평가
- 이해도 평가와 **별도 세션**이다. 사후 퀴즈 뒤 모든 참여자에게 영상을 추가로 보여주어 학습 조건을 오염시키지 않는다.
- 최종 영어 음성+한국어 자막 영상을 직접 재생한다. 가독성, 시차, 말소리 청취, 영어 이해도와 문제 시각을 자기보고한다. 답변 불가도 허용한다.
- 관측된 재생 진행은 플레이어 이벤트 기반 참고치다. 음소거 여부·볼륨도 참고치이며 실제 스피커 출력·참여자 청력·실제 청취 인증이 아니다.
- 사람의 자기보고를 번역 인증, 정확한 오디오 동기 인증 또는 ASR 점수로 바꾸지 않는다.

## 동의·프라이버시·공유
- 명시적인 참여/기기 저장 동의와 사람이 직접 응답한다는 자기선언 후 시작한다. 신원/실제 사람이 응답했는지 자동 인증하지 않는다.
- 이름, 연락처, 녹음, 쿠키 분석, 답변 업로드 API를 사용하지 않는다. 답변은 localStorage에 저장한다. 저장 불가 환경은 안내하고 JSON 내보내기를 제공한다.
- 사용자가 다운로드한 JSON을 직접 공유하기 전에는 운영자가 응답을 보지 못한다. 호스팅의 일반 정적 파일 HTTP 요청/로그는 별개다.
- JSON에는 임의 세션 ID, 문항 응답, 단계 시간, 배정 형식, 화면 크기, 원자료 SHA-256, 동의, 자기선언, 기존 노출, QA flag가 있다. 자유 입력에는 개인정보를 적지 않도록 안내한다.
- 철회 버튼은 기기 저장 답변을 지운다. 이미 다운로드/공유한 파일은 참여자가 별도 삭제/철회를 요청한다.
- `synthetic: true`인 QA fixture와 동의/자기선언 없는 응답은 집계에서 제외한다. flag가 false여도 신원 인증을 의미하지 않는다.
- 실참여는 링크에서 직접 진행하고 JSON을 내보내 대화에 첨부한다. 별도 자동 모집·유료 보상·외부 공유는 수행하지 않았다.

## 분석 재실행
`python3 ops/summarize_human_study.py /path/to/private-submissions`

빈 입력은 0건/평균 null을 반환한다. 실제 응답이 없다고 가짜 평균을 채우지 않는다. 제출된 점수를 신뢰하지 않고 공개 문항 기준으로 다시 계산한다. 개인 원자료/자유 의견은 공개 저장소에 올리지 않는다.
