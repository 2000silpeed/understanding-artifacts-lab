# Korean subtitles and four-format coverage

## Subtitle contract
For a Korean audience with English narration, default to `language.subtitles=ko` and `subtitles.required=true`. Korean diagram labels are not translated narration. Deliver full translated SRT and WebVTT, cue alignment (exact English source words, scene IDs, word ranges and Korean text), a burned-in MP4 for Telegram/social, and a preserved uncaptioned master. Web uses a local Korean subtitle track with toggle plus downloadable transcript; test the actual TextTrack, not merely a `<track>` tag. Chrome treats `file://` files as separate security origins and can reject sidecar WebVTT. For double-click offline delivery, embed the same validated WebVTT into a same-document Blob URL (retain the SRT/VTT sidecars) and test with default browser security; don't hide CORS errors or require relaxed security flags. Seek tests must wait for an actually seekable/buffered media range, not just loaded metadata. The HTTP harness must support byte-range responses (206/Content-Range); a plain server can make media seeking fail even when the files are valid.

Translate the frozen narration before caption grouping. Preserve numbers, units, negation, conditions, illustrative-vs-measured caveats and glossary meanings. Do not translate token labels away when the learner must match them to the chart. Have an independent reviewer compare all English clauses to the Korean cues. A word-coverage check verifies assignment of source timing records, not that spoken audio or translation meaning is perfect.

Cue times come from final audio ASR/alignment. In explainroo, timeline word times are scene-relative; add `scene.start` once. Existing cached words may already include the scene's voice lead. Do not double-add the lead or divide by `pace` twice. If final mux uses `setpts`/`atempo`, apply the exact affine time transform to cue times and record it. Hash the timeline and audit against actual ffprobe duration. Regenerate for any changed narration, cuts, holds, pace or audio offset.

Default operational thresholds: max 2 lines, max 32 Unicode characters per line, minimum 1 second exposure, max 20 characters/second, <=120ms start drift against the source timeline, <=1 second optional end hold. These are configurable house rules, not universal accessibility standards. Account for short source utterances with bounded end holds without overlapping the next cue. Keep captions high contrast, inspect Hangul glyphs and longest cues, and reserve a band; do not cover arrows, formulas or caveats. Inspect decoded frames at cue starts/ends and scene cuts. Recheck at phone size. Automation does not replace human listening or a translation review.

Run:
```
python3 -B scripts/test_audit_captions.py
python3 -B scripts/audit_captions.py BUNDLE --report caption-audit.json
python3 -B scripts/test_audit_bundle.py --report auditor-regression.json
python3 -B scripts/audit_bundle.py BUNDLE --report bundle-audit.json
```
Synthetic cases must reject omissions, duplicate word ranges, bad timestamps, drift, missing sidecars, SRT/VTT divergence, unreadable cues, non-Korean translation, invalid UTF-8, malformed manifests and escaping paths. Never package generated bytecode/cache or private operational files.

## Media binding before release
Bind the declared original video (when present), timeline, final master and final burned-in video to actual SHA-256 values. Set `require_media_binding=true`; verify every declared hash and reject missing required bindings. Changing fonts/re-rendering invalidates the old final-media hash: reseal/re-audit after the final render. File identity does not establish audible sync or translation correctness.

## What the original four formats mean
Karpathy's source lists **Writing; Diagrams / images; Web pages; Explainer videos**. They are four output formats, not four subjects, and the original preference for video is not a proven universal learning ranking. A reuse test must cover each mechanism, not just route names:
- Writing: terms, conditions and caveats, claim-to-source traceability, readable prose and a prediction question. Sentence lint is not ASD-STE100 certification.
- Diagram/image: explain arrow meaning, causal/data-flow order, matching quantities and labels, a misconception/counterexample, and real rendered geometry/glyphs. Static sentence cards don't count as explanatory diagrams.
- Web: meaningful intervention, correct recomputation, edge cases/reset/seed behavior, keyboard/focus, mobile control visibility, offline resource loading, actual video and captions toggle.
- Video: observable timed causality, same declared examples, correct marker/cumulative interval geometry, actual decode/audio properties, translated subtitle completeness/sync and caption-safe layout.

## Additional tests beyond one worked example
1. Cross-format fact matrix: mark every central claim/assumption and where it appears. Differences in seeds/draws must be explicit; outputs need not match when inputs differ.
2. Fresh topic transfer: make all four formats for at least two genuinely different domains (e.g. a code path and a non-probabilistic physical mechanism). Verify source accuracy and behavior again. Passing one LLM-sampling example does not validate general reuse.
3. Requirements: check requested duration/resolution/languages separately from codec validity. Disclose or fix any unmet limit.
4. Caption player: local offline WebVTT load, active-cue text at selected times, seek across scene boundaries, keyboard toggle, mobile readability, disabled audio viewing.
5. Published artifact: download the actual release asset, verify byte count, ZIP CRC and every manifest SHA-256; an upload success is not download integrity.
6. Learner evaluation: with consenting people, compare formats using common prior-knowledge questions and equal exposure, changed-case predictions, misconception checks and delayed retention. Record sample/protocol/uncertainty. No people tested means no measured comprehension claim. An LLM reviewer or ASR match score is only a separate proxy.

Report each as passed, failed, not run or not applicable, with actual evidence. A fresh-topic or learner study may remain not run without blocking a narrowly scoped technically verified example; it does block generalized effectiveness claims.
